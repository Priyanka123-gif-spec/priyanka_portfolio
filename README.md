# Priyanka Hirapara — Product Manager Portfolio

A responsive single-page professional portfolio inspired by the **section structure** of [Sneh Malani's portfolio](https://snehmalani.github.io/sneh-malani-portfolio/) and customized with Priyanka Hirapara's supplied CV.

## Preview locally

Open `index.html` in a browser. No build tools, Node.js, or dependencies are needed. Google Fonts requires an internet connection; browser fallback fonts are available.

## Publish on GitHub Pages

1. Sign in to GitHub and create a new **public repository**, for example `priyanka-portfolio`.
2. Upload **all three files** (`index.html`, `styles.css`, `script.js`) and optionally this README to the repository root.
3. In your repository, go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/ (root)` and save.
5. Your URL will be `https://YOUR-USERNAME.github.io/priyanka-portfolio/` (replace `YOUR-USERNAME` with your GitHub username).

## Before publishing

- Check all external product links; they come from hyperlinks embedded in the supplied CV. A few product names in the original CV are ambiguous, so verify that each store listing corresponds to the intended product.
- There is no email address in the CV, so contact uses LinkedIn and the provided phone number. If you prefer privacy, remove the phone links from `index.html` before publishing.
- The CV contains placeholders such as `[X%]` for unconfirmed metrics. These are **not** included on the website; add verified figures when available.
- No headshot, product screenshots, or downloadable resume are included because none were supplied as verified website assets.

## Edit content

All sections and external links can be edited directly in `index.html`. Colors, typography, spacing, and mobile layout can be adjusted in `styles.css`.
